ИСКУССТВО МОНТАЖА АНИМАЦИИ В PIXAR — ВИДЕОМАТЕРИАЛЫ

Это статический сайт. Сервер или база данных не требуются.

КАК ОТКРЫТЬ САЙТ
1. Откройте index.html в современном браузере.

КАК ЗАМЕНЯТЬ ССЫЛКИ
Откройте app.js и найдите блок videoLinksText.
Каждая строка имеет формат:

  НОМЕР - ССЫЛКА

Например:
  1.1 - https://rutube.ru/video/ВАШ_ID/
  1.2 - https://rutube.ru/video/private/ВАШ_ID/?p=ВАШ_КЛЮЧ
  1.3 - https://youtu.be/ВАШ_ID
  1.4 - https://www.youtube.com/watch?v=ВАШ_ID
  1.5 - https://vimeo.com/ВАШ_ID
  1.6 - https://vimeo.com/manage/videos/ВАШ_ID

Сайт автоматически определяет видеохостинг по ссылке и преобразует обычную ссылку в адрес встроенного плеера.

ПОДДЕРЖИВАЮТСЯ
- RUTUBE: обычные ссылки /video/ID/
- RUTUBE: приватные ссылки /video/private/ID/?p=КЛЮЧ
- YouTube: youtu.be/ID, youtube.com/watch?v=ID, /shorts/ID, /live/ID
- Vimeo: vimeo.com/ID и vimeo.com/manage/videos/ID
- Также можно вставить уже готовую embed-ссылку RUTUBE, YouTube или Vimeo.

ВАЖНО ПРО ПРИВАТНЫЙ RUTUBE
Для видео RUTUBE с доступом «Только по ссылке» ссылка должна содержать ключ доступа ?p=....
Сайт автоматически переносит этот ключ в embed-ссылку. Без ключа приватное видео воспроизводиться не будет.

ВАЖНО ПРО VIMEO
Ссылка вида vimeo.com/manage/videos/ID — это административная ссылка Vimeo. Сайт преобразует её в player.vimeo.com/video/ID, но само видео должно разрешать встраивание на сторонние сайты. Если Vimeo ограничивает embed, понадобится обычная публичная/разрешённая для встраивания ссылка.
